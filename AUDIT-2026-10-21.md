# Security Audit — sip-01-core — 2026-10-21 (first audit; no audit/2026-10 baseline)

## Summary
Reusable SIP-01 (kind 39697) reference implementation and search-engine core library (TypeScript, published as a library with peer deps on nostr-tools/@nostrify/react). No server component, no secrets, no signing of user keys. Main observations are privacy-oriented: the CORS-proxy failover pool and third-party provider calls leak request URLs to external proxies by design. Findings: 0 CRITICAL / 0 HIGH / 0 MEDIUM / 2 LOW.

## Findings
| ID | Severity | File/Area | Issue | Recommended fix |
|----|----------|-----------|-------|-----------------|
| CORE-L1 | LOW | src/lib/corsProxy.ts | All browser-blocked HTTP calls (SearXNG, DDG, Brave, AI providers) route through third-party public CORS proxies (proxy.shakespeare.diy, allorigins.win, codetabs.com) — search queries/URLs leak to those operators, and a malicious proxy can observe/alter non-authenticated traffic | Document prominently; prefer first-party/self-hostable proxy; warn before sending AI-provider requests through proxies |
| CORE-L2 | LOW | repo | No SECURITY.md; GHAS secret scanning not enabled | Add SECURITY.md; enable scanning |
